# 5. Multi-Language Support (Localization)

1. Open the **Localization** tab and confirm your **Source / Default Language** (such as `en` or `id`).
2. Under **Add Language**, enter a language code (e.g., `ja`, `ko`, `fr`) and display name, then click **+ Add Language**.
3. Click **Sync Strings** whenever you add new dialogues or choices in your scenes.
4. Translate directly in the editor or use **Export CSV / Import CSV** (`key,context,source,translation`) to edit in Excel or Google Sheets.
5. Players can switch languages anytime from **Settings -> Language** in the exported game.
