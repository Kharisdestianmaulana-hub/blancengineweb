# 3. Editing Scenes & Story Flow

- **Scene Editor**: Fine-tune vertical action blocks including backgrounds, character positioning and expressions, dialogue, narration, choices, wait timers, and screen effects (`FadeIn`, `FadeOut`, `FlashWhite`, `Shake`).
- **Story Flow**: Visually wire `Main Menu`, `Scene` nodes, `Choice` pins, `Pause`, `Settings`, and `Ending` nodes on an interactive node canvas.
