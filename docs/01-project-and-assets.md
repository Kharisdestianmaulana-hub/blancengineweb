# 1. Creating a Project & Importing Assets

Download and open **Blanc Engine** (`Setup.exe` or `Portable.exe`), click **New Project** (or open an existing project), and import your assets in the **Asset Manager**:

- **Backgrounds**: `.png`, `.jpg`, `.webp` (recommended resolution 1920x1080)
- **Characters**: Sprites & expression variants with transparent backgrounds
- **Audio**: BGM (looping tracks), SFX (sound effects), and Voice acting clips
- **UI & Fonts**: Custom UI textures, buttons, nine-slice panels, and `.ttf`/`.otf` font files
